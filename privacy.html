Privacy Policy for Sidekick

Last Updated: June 2026

Overview

Sidekick is a Chrome extension that helps users understand and explore webpages with AI-powered explanations, search, and chat.

Information We Collect

Sidekick does not automatically collect personal information for the developer. Text selected by the user may contain personal information; selection capture stores it locally, and page or selection content is sent to Google only when the user requests an AI response.

When selection capture is enabled, selected text and nearby page context are stored locally in the browser so they remain available after the popup closes. The extension may read webpage content to provide contextual explanations. Page content is sent to Google's Gemini API only when the user requests an AI explanation, Find result, or Ask AI response.

API Key Storage

Users provide their own Google Gemini API key. The API key is stored locally in the user's browser using Chrome storage APIs and is not transmitted to the developer.

Third-Party Services

When users request an AI response, relevant webpage content and the user's prompt may be sent to Google's Gemini API. Requests are made by the extension's background service worker using the user's locally stored API key.

Data Sharing

Sidekick does not sell user data and does not use information for advertising or marketing purposes.

Contact

For questions regarding this Privacy Policy, please contact the project maintainer through the GitHub repository.
